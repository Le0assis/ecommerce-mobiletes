# Documentação da LUME

Este diretório é o contexto do produto para o dono e para quem for alterar o código, inclusive um agente de IA. O guia de instalação para quem está começando do zero continua no [README.md](../README.md) da raiz. O contrato de produto e os requisitos numerados estão em [REQUISITOS-TECNICOS.md](REQUISITOS-TECNICOS.md).

Leia nesta ordem se for a primeira vez:

1. [Visão geral](visao-geral.md) — o que a loja é e o que esta versão entrega.
2. [Arquitetura](arquitetura.md) — quem calcula o preço e quem só mostra.
3. [Stack](stack.md) — o que foi escolhido e por quê.
4. [Estrutura](estrutura.md) — pastas.
5. [Funcionalidades](funcionalidades.md) — cada fluxo, onde mora, como estender.
6. [Modelo de dados](modelo-de-dados.md) — entidades e o que é demonstração.
7. [API](api.md) — contratos `/v1`.
8. [Design system](design-system.md) — cor, tipo, movimento.
9. [Operação](operacao.md) — rodar, testar, publicar.
10. [Convenções](convencoes.md) — como o código se escreve.
11. [Como fazer](como-fazer.md) — produto, página, componente, meio de pagamento.
12. [Decisões](decisoes.md) — ADRs.
13. [Roadmap](roadmap.md) — o que já está e o que falta, por dependência.
14. [Deploy](deploy.md) — publicar vitrine e API sem credencial de pagamento.

`apps/storefront/AGENTS.md` é o guia de versão do Next.js. Não é este índice.
